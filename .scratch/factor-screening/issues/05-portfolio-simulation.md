# 05 — 组合模拟与成本模型

Status: ready-for-agent
Type: task
Blocked by: 04

## 目标

实现 `factor_portfolio.py`：把筛选通过的因子合成横截面打分，模拟美元中性组合的净值、换手与容量。

## 交付物

- 组合：long top-K / short bottom-K，默认 K=5（K=8 作敏感性）；等风险权重、单名上限 20%、
  目标年化波动 15%、杠杆上限 2x；每日 00:00 UTC 调仓（4H 作对照）。
- 容量：单标的成交额 ≤ ADV 的 0.5%，输出当前流动性下可承载规模的估算。
- 成本：逐笔计入 taker/maker 费、滑点与资金费；换手率显式报告。
- 基准：BTC 买入持有、等权宇宙、SPY 永续买入持有。

## 验收标准

1. 净值曲线与成本明细逐项可对账（毛收益 − 手续费 − 滑点 − 资金费 = 净收益）。
2. 流动性过滤使用重平衡时刻可观测的过去 7 日 ADV，不使用未来数据。
3. 组合对单名无超额暴露：任一标的权重 ≤20%，且美元中性敞口在阈值内。
4. 输出容量估算与「策略在多大资金规模下失效」的临界点。
5. 与三个基准的对比表包含风险调整指标（Sharpe、Calmar、最大回撤、相对基准超额）。
