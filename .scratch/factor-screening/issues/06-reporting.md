# 06 — 报告与结论固化

Status: ready-for-agent
Type: task
Blocked by: 05

## 目标

把研究结论写成可复核、可交接的文档，包含正结论与否定结论。

## 交付物

- `.scratch/factor-screening/results/<date>-<universe>.md`：样本设置、成本口径、因子筛选表、
  组合净值与基准对比、容量、失败因子清单、下一步。
- 每个结论附：样本窗口、试验次数、成本假设、FDR 结果、能否外推的边界说明。

## 验收标准

1. 读者不看代码即可判断某个因子是否可信，以及为什么。
2. 明确写出「本结论在什么条件下失效」（费率上升、流动性下降、样本延长）。
3. 与买入持有基准对比，避免只报策略自身收益。
4. 负结论同样完整归档，避免后续重复踩坑。
