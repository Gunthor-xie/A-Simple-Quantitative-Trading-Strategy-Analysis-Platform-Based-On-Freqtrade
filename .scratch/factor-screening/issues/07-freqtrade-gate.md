# 07 — freqtrade 落地闸门

Status: needs-info
Type: task
Blocked by: 05, 06

## 目标

在因子研究给出证据之后，决定是否/如何把组合落到 freqtrade 执行，并明确引擎的能力边界。

## 背景（已核实的摩擦点）

- freqtrade 是「单标的信号驱动」模型，而本研究产出的是横截面美元中性组合，两者不是同一种对象。
- 已有 ADR-0001 的先例：引擎外算特征、引擎内做决策，回测/实盘共用同一份文件。
- 现有代码可复用：`freqtrade_offline.py`（本地 instruments 缓存喂 ccxt 跑离线回测）、
  `PublicDataDownloader`（下载）、`analytics.py`（读本地数据）。
- 本地 `leverage_tiers_USDT.json` 过时，交易股票类前必须刷新。

## 可选落地形态（需在 05/06 结论后选一）

1. **研究管线内模拟执行**：组合留在 `factor_portfolio.py`，用于 dry-run 级别的持续验证（推荐先做）。
2. **freqtrade 策略承载**：`max_open_trades ≥ 2K` + `custom_stake_amount` 表达权重 + 策略读取预计算
   因子文件（ADR-0001 模式）；需接受单标的信号模型带来的表达损耗。
3. **不落地**：若未通过闸门，归档结论并停止投入。

## 验收标准（待 05/06 完成后填入具体数值）

1. 明确写出所选形态与理由，以及与 ADR-0001 的一致性。
2. 若选形态 2：给出 freqtrade 回测与 `factor_portfolio.py` 模拟净值的一致性对照（差异量化）。
3. 明确风险上限：最大杠杆、单名上限、总敞口、最大回撤停机线。
4. 实盘前必须有 dry-run 观察期，并记录真实成交与模拟的偏差（费率、滑点、资金费）。

## Comments

### 2026-09-25 — 闸门结果：无候选通过，暂不落地

- 加密池：FDR 显著因子（`vol_7d`、`amihud` 等）组成的美元中性组合 -9.97%（Sharpe -0.58），
  K=3/5/8 与费率 2/5/10 bps 全部为负，仅多头与仅空头同样为负。
- 股票池：入选组合 +3.82%（Sharpe 0.57），但 K=3/5/8 → +10.4%/+3.8%/-10.7%，
  换手 1.17、年度成本 11.8% —— 结果由成本与参数决定，不是由信号决定。
- 因此**不进入形态 1/2**（研究管线内模拟执行、freqtrade 策略承载均不启动），
  保持 `needs-info`。重新评估的前置条件见 spec §14.5：补样本、改因子口径、把换手降到 0.2 以下。
