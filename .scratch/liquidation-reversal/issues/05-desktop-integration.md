# 05 — 桌面端集成：数据下载、覆盖率与清算事件展示

Status: ready-for-agent
Type: task

## 目标

把清算特征的生产与消费接进现有桌面端，让用户不需要敲 CLI 就能完成
"下载清算数据 → 生成特征 → 查看事件 → 回测 → 看图"的闭环。

## 范围

1. **数据下载页**：新增"清算/级联特征"下载类型（pair + 日期区间 + 是否含 aggTrades），
   复用 `PublicDataDownloader` 的代理发现与进度回调；后台任务走现有 job 机制。
2. **覆盖率**：`coverage.py` 增加特征文件覆盖率（起止时间、分钟数、缺失比例、
   是否含真实强平流），在 UI 上以警告形式提示"该区间为代理模式（无真实强平）"。
3. **信号与交易页**：展示最近触发事件表（时间、方向、1 分钟涨跌、flush 分、
   强平金额/分位、盘口失衡）并把事件点标注到 K 线图（复现"20:37–20:38"这类级联）。
4. **API**：`POST /api/liquidation/build`（生成特征）、`GET /api/liquidation/coverage`、
   `GET /api/liquidation/events?pair=&start=&end=`。
5. **测试**：API 冒烟 + 覆盖率解析 + 事件筛选，沿用 `backend/tests` 现有风格。

## 验收

- 从 UI 触发一次 1 天 BTC 特征生成，进度可见，完成后信号页能看到事件点。
- 缺少特征文件的策略在回测页给出明确提示（而不是静默 0 交易）。
